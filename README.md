# Guide complet du crafting DayZ Vanilla (2024-2025)
## Version française avec traductions

Le système de crafting de DayZ reste l'un des plus profonds du genre survie, avec plus de **100 recettes** couvrant l'alimentation, la médecine, la construction et l'équipement improvisé. Ce guide exhaustif pour la version vanilla PC (Chernarus Plus) détaille chaque craft essentiel.

---

## 🩸 Transfusion sanguine

### Équipement de transfusion

| Nom en jeu | Traduction FR | Utilité |
|------------|---------------|---------|
| **Blood Test Kit** | Kit de test sanguin | Révèle ton groupe sanguin (permanent) |
| **Blood Bag Kit** | Kit de poche de sang | Prélève ~500 unités de sang |
| **IV Start Kit** | Kit de perfusion IV | Nécessaire pour transfuser |
| **Blood Bag IV** | Poche de sang IV | Blood Bag + IV Start Kit combinés |
| **Saline Bag** | Poche de sérum physiologique | Régénère sang (universel) |
| **Saline Bag IV** | Perfusion de sérum | Saline Bag + IV Start Kit |

### Procédure de transfusion

1. **Tester** ton groupe sanguin avec Blood Test Kit
2. **Tester** le groupe du donneur
3. **Vérifier la compatibilité** (tableau ci-dessous)
4. **Prélever** le sang du donneur avec Blood Bag Kit
5. **Combiner** Blood Bag + IV Start Kit = Blood Bag IV
6. **Transfuser** le receveur

### Tableau de compatibilité sanguine

| Ton groupe | Traduction | Tu peux recevoir de | Tu peux donner à |
|------------|------------|---------------------|------------------|
| **O-** | O négatif | O- uniquement | **TOUS** (donneur universel) |
| **O+** | O positif | O+, O- | O+, A+, B+, AB+ |
| **A-** | A négatif | A-, O- | A+, A-, AB+, AB- |
| **A+** | A positif | A+, A-, O+, O- | A+, AB+ |
| **B-** | B négatif | B-, O- | B+, B-, AB+, AB- |
| **B+** | B positif | B+, B-, O+, O- | B+, AB+ |
| **AB-** | AB négatif | AB-, A-, B-, O- | AB+, AB- |
| **AB+** | AB positif | **TOUS** (receveur universel) | AB+ uniquement |

⚠️ **Transfusion incompatible = Réaction hémolytique = MORT possible !**

💡 **Saline Bag IV** est **toujours compatible** avec tout le monde et régénère ~500 unités de sang en 3 minutes.
